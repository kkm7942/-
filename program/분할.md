# 주간 운동 프로그램

> ⚠️ **잠정안** — 스케줄(주 N회·요일)과 헬스장 기구 환경이 확정되면 코치가 조정한다.
> 근거: 인바디상 **근육 증량 국면 + 상체 볼륨업 우선**(다리 표준이상, 팔·몸통 표준).

## 설계 원칙
- 목표: 골격근량 회복·증량. 감량 아님 → 유산소는 보조(주 1~2회 20분 이하).
- 상체 볼륨을 하체보다 1.5배 배분. 다리는 유지 위주.
- 각 종목 10~12회(어깨·팔·코어는 12~15회) 작업, 정체 시 처방 로직 순서대로.

## 잠정 주 3회 분할 (상체-하체-전신)

### Day A — 상체 집중 (우선순위)
1. 체스트프레스 3세트
2. 랫풀다운 3세트
3. 숄더프레스 3세트
4. 시티드로우 3세트
5. 사이드레터럴 3세트
6. 바이셉컬 / 트라이셉푸시다운 각 2세트

### Day B — 하체 (유지 볼륨)
1. 레그프레스 3세트
2. 힙쓰러스트 3세트
3. 레그컬 3세트
4. 레그익스텐션 2세트
5. 플랭크 3세트

### Day C — 전신 + 상체 보강
1. 덤벨프레스 3세트
2. 덤벨로우 3세트
3. 숄더프레스 or 사이드레터럴 3세트
4. 레그프레스 2세트
5. 코어 2세트

## deload
- 4주마다 1주: 무게 60~70%, 세트 절반. 회복 주간.
