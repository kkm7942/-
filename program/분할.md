# 주간 운동 프로그램 — 주 7회

> 목표: **현상 유지 + 체지방 관리** (코치 해석: 근육 지키며 컨디션 유지 — CLAUDE.md 경계 참조)
> 기구: 머신 + 프리 둘 다 · 제약: **왼쪽 고관절** (하체·스텝밀 종목 통증 테스트 우선)

## 주간 배치
| 요일 | 세션 | 유산소 |
|---|---|---|
| 평일 A | **하체** | +30분 |
| 평일 B | **등** | +30분 |
| 평일 C | **가슴 + 팔** | +30분 |
| 평일 D | **어깨 + 팔** | +30분 |
| 평일 E | **보강·코어**(또는 약점 부위 1개) | +30분 |
| 주말 2일 | 유산소만 | 런닝머신 30분 + 천국의계단 20분 |

> 평일 5일 중 A~D는 4대 분할, E는 보강일. 요일 고정 원하면 알려줘 — 캘린더로 못박아줌.

## 세션별 종목 (머신·프리 혼용, 각 10~12회 / 어깨·팔·코어 12~15회)

### 하체 — ⚠️ 왼쪽 고관절 프로토콜
- **시작 전 가벼운 무게로 좌측 고관절 통증 테스트.** 당김·걸림 있으면 그 종목 스킵.
- 레그프레스(발 간격 좁게~중간, 깊이 통증 없는 범위) 3세트
- 레그컬 3세트 / 레그익스텐션 3세트 (고관절 부담 적음 — 안전 종목)
- 힙쓰러스트 **가벼운 무게부터** 3세트 (좌측 자극 체크하며 점진)
- 깊은 스쿼트·와이드 런지·무거운 힙 힌지는 통증 확인 전 보류

### 등
- 랫풀다운 3세트
- 시티드로우 3세트
- 덤벨로우 or 어시스트 풀업 3세트
- 백 익스텐션은 고관절 자극 있으면 스킵

### 가슴 + 팔
- 체스트프레스(머신) 3세트
- 덤벨프레스 or 펙덱 3세트
- 트라이셉 푸시다운 3세트
- 바이셉 컬 3세트

### 어깨 + 팔
- 숄더프레스 3세트
- 사이드 레터럴 레이즈 3세트
- 리어델트(펙덱 리버스) 2세트
- 바이셉/트라이셉 각 2세트

### 보강·코어 (평일 E)
- 코어: 플랭크 / 데드버그 등 3세트 (고관절 굴곡 강한 동작 피함)
- 약점 부위 1개 추가(상체 볼륨 권장)

## 유산소 규칙
- 평일: 웨이트 후 30분.
- 주말: 런닝머신 30분 + 천국의계단 20분.
- **천국의계단은 좌측 고관절 반복 굴곡 종목** → 당김 오면 즉시 경사 낮추거나 런닝/사이클/일립티컬로 대체. 통증 참고 진행 금지.

## deload
- 4주마다 1주: 웨이트 무게 60~70%·세트 절반, 유산소 강도 낮춤. 고관절·관절 회복 주간.
